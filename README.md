# Página de Captura - Aula Gratuita

Site estático para a aula gratuita:

**Pare de medir curtidas. Comece a construir algo que pode ser vendido.**

## Arquivos

- `index.html`: estrutura da página.
- `styles.css`: visual da página.
- `assets/`: coloque aqui a foto do Thiago como `thiago.jpg`.

## Próximos encaixes

1. Substituir os blocos `COLE AQUI O CÓDIGO DO FORMULÁRIO` pelo código real do formulário.
2. Adicionar a nova foto do Thiago em `assets/thiago.jpg`.
3. Revisar no navegador em desktop e celular.
